# Mushroom Genus Classification

Небольшой проект по распознаванию грибов по изображениям. Основная задача — определить род гриба среди 9 классов по фото.

## Задача

В ноутбуке [mushrooms.ipynb](mushrooms.ipynb) реализована задача мультиклассовой классификации изображений грибов:

- 9 классов (родов): Agaricus, Amanita, Boletus, Cortinarius, Entoloma, Hygrocybe, Lactarius, Russula, Suillus
- общий набор данных: 6714 изображений
- разбиение на обучающую и валидационную выборки с сохранением баланса по классам

Цель — получить высокую точность классификации.

## Решение

В решении использован подход transfer learning:

- загрузка предобученных моделей: ResNet-50 или ConvNeXt-Tiny
- заморозка backbone на первом этапе обучения
- добавление классификационной головы поверх извлечённых признаков
- обучение с аугментацией изображений (crop, flip, rotation, affine transforms)
- использование weighted cross-entropy для компенсации дисбаланса классов
- подбор лучшей модели по метрике accuracy/F1 на валидации

Также в ноутбуке реализованы:

- подготовка датасета и разметки
- кастомный `Dataset` для загрузки картинок
- вычисление метрик (`accuracy`, `macro F1`, classification report)
- построение графиков обучения и визуализация предсказаний

## Результаты

По итогам обучения лучшая модель показала следующие результаты на валидации:

- Accuracy: 95.93%
- Macro F1: 95.27%

Сравнение моделей:

| Backbone | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| ResNet-50 | ~93.00% | ~92.00% |
| ConvNeXt-Tiny | 95.93% | 95.27% |

Таким образом, ConvNeXt-Tiny оказался более точным и показал лучший результат по обеим метрикам.
